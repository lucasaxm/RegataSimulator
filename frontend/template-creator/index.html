Enviar template ao bot

  1. Copiar dados.
  2. Anexar a imagem original como Arquivo/documento no bot.
  3. Colar os dados na legenda e enviar.

Depois, siga a confirmação no bot. O template passa pela aprovação da administração.

Reutilizar ou guardar dados

Cole dados de outro template no campo acima para aplicar suas áreas à imagem atual.
